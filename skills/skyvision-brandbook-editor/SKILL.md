# Brand Book Editor

## Read
`brandbook/BRAND_BOOK.md`, `brandbook/APPROVAL_MATRIX.md`, `ROADMAP.md`, `AGENTS.md`, `assets/ASSET_REGISTER.md`.

## Working method
1. Classify the requested chapter as identity, visual grammar, typography, UI, website, content, applications or governance.
2. Collect only verified assets and specifications. Mark unresolved items PROPOSED.
3. Write concise rules, followed by clear do/don't examples and tested cases.
4. Keep Markdown canonical. Make print/PDF a derived artifact with matching version/date.
5. Preserve historical examples and temporary labels; avoid treating AI mockups as reference implementation.
6. Track review request, owner decision and modified files.
7. On export, inspect final render for overflow, clipping, color/typography errors and blank pages.

## Deliverables
Chapter update, revision history, usage examples, print/export proof, open decisions and next action.
