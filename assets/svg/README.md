# Sky Vision SVG motif candidates

These seven SVGs are **original editable studies**, not approved final logos. Open in browser, Figma or Illustrator; all have a viewBox and no raster dependencies.

| File | Purpose |
|---|---|
| skyvision-symbol.svg | Full illustrative mark study (large sizes) |
| skyvision-symbol-compact.svg | Simplified 64x64 icon study |
| skyvision-wave-divider.svg | Decorative marketing section transition |
| skyvision-orbits.svg | Sparse orbital background / editorial framing |
| skyvision-crescent-motif.svg | Isolated crescent decoration; transparent background |
| skyvision-cloud-curl-motif.svg | Isolated cloud and ribbon decoration; transparent background |
| skyvision-compass-star-motif.svg | Isolated compass star decoration; transparent background |

The three standalone motif files are independent, scalable SVG assets with no background rectangle. They are supporting decorations and must not be substituted for or used to reconstruct the primary circular logo.

Do not deploy the detailed symbol as a 16px icon without legibility tests. Proposed colors come from `tokens/skyvision.tokens.json`. Trace original raster inspiration separately and never overwrite it.
