# Approved / Proposed Production Visuals

This directory contains draft production visuals and GIF studies. **No asset here is approved as final brand identity.** See the machine-readable inventory and asset register for file presence, hashes, status, and limitations.

Related visuals may be generated in batches, then QC-reviewed and iterated as a group. Every image remains an independent deliverable defined in `../../production/ASSET_INVENTORY.json` and scoped by `../../production/ASSET_BACKLOG.md`.

A concept may exist in the conversation but must not be considered present here without a GitHub file and hash verification. Source/user images belong in immutable reference folders and require rights clearance before uploading to this public repository.

Use `../../production/DELIVERY_STANDARD.md` for naming, export and visual acceptance.
