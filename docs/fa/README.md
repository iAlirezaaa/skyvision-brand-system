# اسکای ویژن — راهنمای فارسی

این مخزن **سیستم هویت بصری Sky Vision** است؛ نسخهٔ فعلی هنوز پیشنهادی است، نه برندبوک نهایی تأییدشده.

## جهت هنری
سرمه‌ای عمیق، عاجی، آبی مه‌آلود و طلایی ملایم. موتیف‌ها شامل مدار، هلال، موج، ابر و ستاره‌اند. تصویرپردازی برای هویت و صفحات معرفی استفاده می‌شود؛ اما در جدول‌ها، فرم‌ها و بردهای مدیریت پروژه باید حداقلی باشد.

## اصل محصول
**برنامه کنترل پروژه باید بدون هیچ تصویری هم کاملاً قابل استفاده باشد.** فهرست تسک‌ها، کانبان، وضعیت‌های سفارشی و رنگشان، فیلدهای قابل تنظیم، تایم‌لاین، تقویم و تاریخچهٔ تغییرات باید بر دادهٔ واقعی تکیه کنند، نه جلوه‌های بصری.

## وضعیت تصمیمات
نام Sky Vision نام کاری است. لوگوی نهایی، نمونهٔ دقیق رنگ‌ها، فونت، کپی‌رایت و مجوز انتشار هنوز به تصمیم و تأیید نیاز دارند. نام‌های Lunara و Orbitra فقط در تصاویر مفهومی قدیمی استفاده شده‌اند.

قبل از تغییر اصول برند، ساختار فایل‌ها، هدف محصول یا حذف منابع اولیه باید مشخص باشد: **از چه چیزی → به چه چیزی، چرا، اثرات، مسیر بازگشت و نیاز به تأیید مالک**. هیچ ایدهٔ اصلی نباید در جریان اصلاحات بی‌صدا حذف شود.
