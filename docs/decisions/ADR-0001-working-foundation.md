# ADR-0001 — Working Brand Foundation

- **Date:** 2026-11-03
- **Status:** Proposed (not owner-approved)
- **Context:** A supplied celestial 2D illustration inspired web, mobile, brand and PM product visual experiments.
- **Decision proposal:** Use Sky Vision as the working master brand, preserve the original sources, and document a restrained navy/ivory/blue/gold motif vocabulary. Make the project-management product work with zero images.
- **Not decided:** final logo, font, public distribution/license, trademark, tagline and exact calibrated HEX.
- **Consequences:** Theme parity and SVG motif master files are important; decorative mockups must not dictate product behavior.
- **Reversible:** yes; retain original assets, brandbook versions and decision evidence.
- **Approval:** pending.
