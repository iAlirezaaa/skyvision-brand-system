# Distribution and Asset Rights Policy

The repository is **public**. Existing images include user-supplied reference art and generated exploratory studies. Presence of art in a conversation does **not** prove that redistribution, trademark, font embedding, re-licensing or third-party commercial use is cleared.

Until the owner approves a license and source-specific redistribution:

- Keep original raster assets in a private archive or restricted environment; preserve hashes and provenance in the public manifest.
- Do not publish user-supplied source art, private client names, or proprietary font binaries to public GitHub without verification.
- Do not add an invented commercial or open-source license, or state that the project is MIT/Apache/CC0.
- Treat existing Sky Vision vector and generated visual studies as *proposals*, not trademark-cleared marks.
- Add `LICENSE` only after explicit owner decision; then document scope, third-party exceptions and contributors.

Before promoting an item to production, record: creator/source, original-vs-derived, intended platform, permissions, edit rights, font license/attribution requirements, version and owner review.
